## Reproducer

```python
import socket

seq = []

class Mut:
    def __init__(self):
        self.tripped = False
    def __index__(self):
        if not self.tripped:
            self.tripped = True
            seq.clear()
        return 0

seq[:] = [
    (socket.SOL_SOCKET, Mut(), b'x'),
    (socket.SOL_SOCKET, 0, b'x'),
]
left, right = socket.socketpair()
left.sendmsg([b'x'], seq)
```
