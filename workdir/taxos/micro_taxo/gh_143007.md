## Reproducer

```python
import io

wrapper = io.TextIOWrapper(io.BytesIO(b"x"))

class Cookie(int):
    def __new__(cls, wrapper):
        obj = int.__new__(cls, 0)
        obj.wrapper = wrapper
        return obj
    def __int__(self):
        self.wrapper.detach()
        return 0

wrapper.seek(Cookie(wrapper), io.SEEK_SET)
```
