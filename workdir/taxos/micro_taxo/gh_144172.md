# Micro Taxonomy: CPython #144172

## Metadata
- Issue: https://github.com/python/cpython/issues/144172
- Component: `Python/tracemalloc.c`; subinterpreter teardown
- Bug class: use-after-free
- Detection: AddressSanitizer

## Root Cause
Tracemalloc retains filename objects for traces created while a subinterpreter
starts. Subinterpreter destruction clears its interned strings, freeing a
filename still owned by tracemalloc. Final tracemalloc cleanup decrefs the
stale filename.

## Trigger
1. Start tracemalloc.
2. Create and run a subinterpreter.
3. Destroy the subinterpreter.
4. Interpreter finalization deinitializes tracemalloc.
5. Trace cleanup decrefs a freed filename.

## Reproducer

```python
from concurrent import interpreters
import tracemalloc

# Start tracking memory allocations.
# Tracemalloc captures filenames of code objects loaded during execution.
tracemalloc.start()

# Create a subinterpreter.
# During initialization (specifically _Py_Get_Getpath_CodeObject), 
# the subinterpreter allocates and interns strings (filenames).
# Tracemalloc records pointers to these strings.
interp_id = interpreters.create()

# Ensure the interpreter is fully initialized/used.
interpreters.run_string(interp_id, "pass")

# Destroy the subinterpreter.
# This clears the subinterpreter's interned dictionary, freeing the strings 
# that tracemalloc is still tracking.
interpreters.destroy(interp_id)

# When the script exits, _Py_Finalize calls tracemalloc_deinit.
# Tracemalloc iterates its traces and tries to access the filename strings 
```


## Relevant State
- Owner: subinterpreter interned-string dictionary
- Retained state: tracemalloc filename entry
- Invalidated object: interned filename `str`

## Invalidating Operation
- `_PyUnicode_ClearInterned()` during subinterpreter finalization

## Stale Use
- `tracemalloc_clear_filename()` -> `Py_DECREF()` -> `_Py_IsImmortal()`

## Fix
Give tracemalloc an independent strong reference to recorded filenames, or
clear affected traces before subinterpreter interned strings are released.
