Description
Hi, we found a heap-use-after-free of Array#hash via mutating hash method. Here
is the PoC.
class C
    def hash()
        puts $a
        $a.push(*1..100000)
        return 0
    end
end
c = C.new
$a = [c]
$a.push(*1..10)
$a.hash
puts "!"
puts $a
Calling Array#hash on an array containing an object whose hash method mutates
the array causes memory corruption. In this example, C#hash appends a large
number of elements to $a while Array#hash is iterating over it, leading to
inconsistent internal state and potentially a crash.
To reproduce, compile the recent Ruby with ASAN, and run the PoC.

  <p><strong>Description</strong></p>
  <div id="issue_description_wiki" class="wiki" data-quote-reply-target="content">
  <p>Hi, we found a heap-use-after-free of Array#hash via mutating hash method. Here<br>
is the PoC.</p>
<div class="pre-wrapper" data-controller="clipboard"><a class="copy-pre-content-link icon-only" title="Copy" data-action="clipboard#copyPre"><svg class="s18 icon-svg" aria-hidden="true"><use href="/assets/icons-0476c1d7.svg#icon--copy-pre-content"></use></svg></a><pre data-clipboard-target="pre"><code>class C
    def hash()
        puts $a
        $a.push(*1..100000)
        return 0
    end
end

c = C.new
$a = [c]
$a.push(*1..10)
$a.hash
puts "!"
puts $a
</code></pre></div>
<p>Calling Array#hash on an array containing an object whose hash method mutates<br>
the array causes memory corruption. In this example, C#hash appends a large<br>
number of elements to $a while Array#hash is iterating over it, leading to<br>
inconsistent internal state and potentially a crash.</p>
<p>To reproduce, compile the recent Ruby with ASAN, and run the PoC.</p>
