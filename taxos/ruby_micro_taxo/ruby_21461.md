Description¶
An AddressSanitizer (ASan) heap-buffer-overflow occurs in Ruby when:
The file contains an invalid magic encoding comment, and
A line with incomplete assignment (e.g. missing right-hand side).
This leads to a crash in pm_parse_errors_format_sort, caused by prism_compile.c accessing a freed or uninitialized memory region.

Applied in changeset git|dabdd81d178ed91ca0feb0875ce0df927df0f3fb.
Fix linked list iteration when displaying errors
When a script has problem with the magic comment encoding, we only
display that error.  However, if there are other syntax errors in the
file, the error linked list could contain multiple items.  This lead to
an inconsistency in the "size" field of the linked list, and the actual
items in the linked list.  In other words, the linked list had more than
one item, but the size field was one.
The error display routine would only allocate size items, but
iterating the linked list would overrun the array.  This commit changes
the iterator to compare the current node to the "finish" node in the
linked list, no longer assuming the linked list ends with NULL.

<h3 >Description<a href="#Description" class="wiki-anchor">&para;</a></h3>
<p>An AddressSanitizer (ASan) heap-buffer-overflow occurs in Ruby when:</p>
<ol>
<li>
<p>The file contains an invalid magic encoding comment, and</p>
</li>
<li>
<p>A line with incomplete assignment (e.g. missing right-hand side).</p>
</li>
</ol>
<p>This leads to a crash in pm_parse_errors_format_sort, caused by prism_compile.c accessing a freed or uninitialized memory region.</p>

<hr>
<p>Fix linked list iteration when displaying errors</p>
<p>When a script has problem with the magic comment encoding, we only<br>
display that error.  However, if there are other syntax errors in the<br>
file, the error linked list could contain multiple items.  This lead to<br>
an inconsistency in the "size" field of the linked list, and the actual<br>
items in the linked list.  In other words, the linked list had more than<br>
one item, but the size field was one.</p>
<p>The error display routine would only allocate <code>size</code> items, but<br>
iterating the linked list would overrun the array.  This commit changes<br>
the iterator to compare the current node to the "finish" node in the<br>
linked list, no longer assuming the linked list ends with NULL.</p>
<p>[Bug <a class="issue tracker-1 status-5 priority-4 priority-default closed" title="Bug: Heap-buffer-overflow in Prism when encoding magic comment is invalid and assignment is incomplete (Closed)" href="/issues/21461">#21461</a>]</p></div>
