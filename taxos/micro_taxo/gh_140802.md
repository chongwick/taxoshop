# Micro Taxonomy: CPython #140802

## Metadata
- Issue: https://github.com/python/cpython/issues/140802
- Component: frame initialization; tracing; `asyncio`
- Bug class: heap-buffer-overflow
- Detection: AddressSanitizer

## Root Cause
A trace function assigns an invalid line number while an async coroutine is
executing. Frame evaluation subsequently initializes a frame using state whose
size or instruction position no longer matches the requested control-flow
jump, writing past a 192-byte allocation.

## Trigger
1. Install a trace callback for an async target.
2. On its first line event, set `frame.f_lineno` to a calculated line.
3. Run the coroutine through `asyncio.run()`.
4. An asyncio callback invokes frame evaluation.
5. `_PyFrame_Initialize()` writes one word past the frame allocation.

## Reproducer

```python
import sys
import asyncio

class JumpTracer:
    def __init__(self, func, jump_to):
        self.code = func.__code__
        self.jump_to = jump_to
        self.first_line = None

    def trace(self, frame, event, arg):
        if self.first_line is None and event == 'line' and frame.f_code is self.code:
            self.first_line = frame.f_lineno - 1
            try:
                frame.f_lineno = self.first_line - self.jump_to
            except TypeError:
                frame.f_lineno = self.jump_to
        return self.trace

async def target():
    # Keep a couple of lines so the tracer has places to land.
    x = 0
    x += 1
    return x

if __name__ == "__main__":
    tracer = JumpTracer(target, jump_to=1)
    sys.settrace(tracer.trace)
    asyncio.run(target())
```


## Relevant State
- Owner: coroutine frame allocation
- Mutable state: traced frame line number / instruction position
- Consumer: `_PyEvalFramePushAndInit()`

## Re-entrancy Boundary
- Trace callback invoked during frame execution

## Stale or Invalid Use
- `_PyFrame_Initialize()` in `pycore_interpframe.h:154`

## Fix
Validate trace-requested line jumps against the executing coroutine's legal
instruction boundaries and reject jumps that cannot preserve frame layout.
