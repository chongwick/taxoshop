# Bug report

### Bug description:

LeakSanitizer detects memory leaks in the readline module when running `test_audit`.

### Affected Code
Four functions in `Modules/readline.c`:
- line 298: `PyUnicode_FSConverter` call https://github.com/python/cpython/blob/b2f9fb9db29296410f76009ac65cf81afa8a92a9/Modules/readline.c#L278-L316
- line 342: `PyUnicode_FSConverter` call https://github.com/python/cpython/blob/b2f9fb9db29296410f76009ac65cf81afa8a92a9/Modules/readline.c#L320-L366
- line 399: `PyUnicode_FSConverter` call https://github.com/python/cpython/blob/b2f9fb9db29296410f76009ac65cf81afa8a92a9/Modules/readline.c#L371-L424
- line 255: `PyUnicode_FSConverter` call https://github.com/python/cpython/blob/b2f9fb9db29296410f76009ac65cf81afa8a92a9/Modules/readline.c#L237-L276

### Steps to Reproduce

Build:
```bash
CC=clang CXX=clang++ ./configure --disable-optimizations --with-pydebug --with-address-sanitizer && make -j$(nproc)
```

Run:
```bash
./python -X dev -X showrefcount -m test test_audit -j0
```

### Result
LeakSanitizer reports 4 memory leaks of 75 bytes each (300 bytes total). Full logs attached as .log files.

Summary from LeakSanitizer:
```
SUMMARY: AddressSanitizer: 300 byte(s) leaked in 4 allocation(s).
```

All leaks originate from `PyUnicode_FSConverter` calls in the affected functions.

### CPython versions tested on:

3.14, 3.15, CPython main branch

### Operating systems tested on:

Linux
