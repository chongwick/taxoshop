````text
One thing worth putting on the record before a fix is written, because it rules out an approach that looks obvious: **`@critical_section` provides no mutual exclusion across a GIL-released region.**

```c
if (tstate->critical_section != 0) {
    _PyCriticalSection_SuspendAll(tstate);

So any critical section held on entry is *suspended* for the duration of a `Py_BEGIN_ALLOW_THREADS` / `PySSL_BEGIN_ALLOW_THREADS` block, and re-acquired on reattach.
````
