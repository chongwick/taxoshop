### Bug description:

```python
import tempfile
import os
import fcntl

nbytes = 2024
tf = tempfile.NamedTemporaryFile(delete=2**15 - 1)
tf_name = tf.name

with open(tf_name, 'wb') as f:
    get_result = fcntl.fcntl(f, fcntl.F_GETOWN_EX, b'' * nbytes)
```
