# Micro Taxonomy: CPython #140860

## Metadata
- Issue: https://github.com/python/cpython/issues/140860
- Component: audit hooks and time-formatting path
- Bug class: indirect memory leak
- Detection: LeakSanitizer

## Root Cause
The report installs an audit hook that retains every event and argument tuple,
then invokes a time-formatting path. It reports indirect leaks, but the
published reproducer calls an undefined `roundtrip` helper, so the exact
CPython ownership failure is not established.

## Trigger
1. Register an audit hook that appends event arguments to a list.
2. Invoke the intended time-formatting round-trip path.
3. Exit with the audit-hook event list still reachable.
4. LeakSanitizer reports indirect allocations.

## Relevant State
- Hook: `sys.addaudithook()` callback
- Retainer: Python list of `(event, args)` tuples
- Reproducer caveat: `roundtrip` is undefined in the submitted snippet

## Leak Path
The report cannot distinguish retained Python-level audit data from a native
leak because the reproducer is incomplete and the hook intentionally stores
arguments.

## Fix
Provide a self-contained reproducer, clear the event list before exit, and
then identify any allocation that remains independently reachable.
