### Original Issue

Source: [https://github.com/python/cpython/issues/143310](https://github.com/python/cpython/issues/143310)

````text
### What happened?

Passing a list that contains an object whose `__str__` clears the list lets `_tkinter`’s `AsObj` recurse through `PyObject_Str`, which mutates the list while the outer loop still walks it. The subsequent `PySequence_Fast_GET_ITEM` hits a NULL slot and crashes the interpreter.

**Proof of Concept:**
```python
import tkinter

interp = tkinter.Tcl()

victim = []

class Evil:
    def __str__(self):
        victim.clear()
        return "boom"

victim[:] = [Evil(), "pad"]
interp.call('set', 'var', victim)
```
````
