```text
From a conversation with @brandtbucher, the first two can be resolved by [commenting out the `pop_4_error` and `pop3_error` cases in `bytecodes.c`](https://github.com/python/cpython/blob/v3.14.0a7/Python/bytecodes.c#L5228-L5238).

The "unreachable code" is the automatically injected content that is done for cleanup after the return. The suggestion was that the code generator needs to be taught about that edge case so it doesn't inject the stack cleanup code.
