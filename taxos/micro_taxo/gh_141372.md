```text
Feel free to take a look, but my gut feeling is that this is not worth investigating. The repro code replaces `sys.monitoring` and uses `cProfile` which relies on it. `sys.monitoring.MISSING` is designed to be a singleton so I wouldn't be surprised if there's some leak when you do things like this. If it's a segfault or a buffer overflow we should probably avoid it, but it's a memory leak. That being said, if you can find why this happens and figure out a clean solution, it could still be merged. But if it takes a large refactor, it may not worth it.
```
