The crash is because we insert a non-unicode key into a dict that only supports unicode keys.

We check for this case at the beginning of `insertdict()`:

https://github.com/python/cpython/blob/95e5d596308620acbd860ec25a40ef95c2b62eaa/Objects/dictobject.c#L1877-L1881

But then the lookup clears the dict (going back to the empty keys, which are marked as unicode only):

https://github.com/python/cpython/blob/95e5d596308620acbd860ec25a40ef95c2b62eaa/Objects/dictobject.c#L1898-L1912

And when `insert_combined_dict` resizes, it keeps the keys object as unicode-only.

https://github.com/python/cpython/blob/95e5d596308620acbd860ec25a40ef95c2b62eaa/Objects/dictobject.c#L1778-L1783
