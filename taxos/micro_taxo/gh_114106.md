````text
# Crash report

### What happened?

PoC:
```python
xxx = """
import gc
class Cls:
	var = []
gc_get_referrers_list=gc.get_referrers(Cls.var)
for ref in gc_get_referrers_list:

gc.collect(gc_collect_arg0)
````

````text
This most likely has the same root cause  as #113631.

This code is enough to cause the invalid state, since it is mutating the underlying dict without updating the type cache.
```py
import gc
class Cls:
	var = []
gc_get_referrers_list=gc.get_referrers(Cls.var)
for ref in gc_get_referrers_list:
	del ref['var']
```
	
Afaik, there is no plan to fix this, since it has been a known issue for at least 14 years as noted in [this crasher](https://github.com/python/cpython/blob/main/Lib/test/crashers/underlying_dict.py)
````
