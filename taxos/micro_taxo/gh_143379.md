## Reproducer

```python
import struct

S = struct.Struct('?I')

class Evil():
    def __bool__(self):
        # Reinitialize the struct while Struct.pack() is iterating over s_codes.
        # The new format frees the previous codes array, leaving the active
        # iterator with dangling pointers.
        S.__init__('I')
        return True

S.pack(Evil(), 0)
```
