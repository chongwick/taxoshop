```text
This looks legit.

The problem occurs in `_elementtree_XMLParser__setevents_impl`. Specifically, there are two references to `events_queue`, one by `events_seq` indirectly due to `PySequence_Fast`, and one indirectly by `event_name_obj` which accesses the container's contents. We decref the container that holds the contents (including the string), causing the underlying string buffer to be freed. We then pass the string buffer to an exception builder.

The fix is to reorder the decref.
```
